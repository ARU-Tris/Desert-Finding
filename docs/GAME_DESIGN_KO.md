# Desert Finding — 게임 설계 V2

이 문서는 기존 V1 설계를 대체한다. 목적지가 없는 사막 방랑 게임이다. 플레이어는 사하라 규모 사막의 중심에서 시작한다. 지정 방위각, 목적지, 퀘스트, 지도, 목표 표시가 없다. 실제 월드 좌표가 자연적인 사막 경계를 넘어갈 때만 엔딩이 발생한다. 모든 방향의 경계로 나갈 수 있다.

## 물리적 규모

- 면적: 9,200,000 km² = 9.2e12 m², 수치 적분으로 ±2% 이내 보정.
- 형태: 동서로 긴 매끄러운 불규칙 방사형 경계. 실제 지리 지도는 아니며 사하라의 규모를 모사한다.
- 좌표: 미터 단위, 동 +X / 남 +Y / 북 -Y.
- 보행: 정확히 5000 / 3600 m/s (5 km/h), 스태미나 제한 없음.
- 시각 변환: 32.4 논리 픽셀/미터 → 기존 45px/s 유지.
- 기본 시드 90210: 북 1,245km, 동 2,132km, 남 1,303km, 서 2,446km. 직선 기준 약 249/426/261/489시간의 실제 활성 플레이가 필요하다.
- 등면적 원: 반지름 약 1,711km, 342시간 / 14.26일 연속 보행. 이동 시간을 축소하거나 근처 출구를 만들지 않는다.
- 약 2km 안쪽부터 마른 풀, 돌, 식생이 점차 나타나고 마지막 120m는 더 뚜렷한 초지/관목지 색으로 바뀐다.

## 방향 감각과 나침반

마지막 클릭 방향 intendedHeading과 실제 이동 방향 actualHeading을 분리한다. 시드 기반의 연속적인 상관 각속도로 여러 분/시간에 걸쳐 방향 오차가 축적된다. 반복적인 풍경과 밤에는 더 강하고, 햇빛/그림자/인식할 만한 경계 식생은 오차를 줄인다. 오랜 무보정 보행은 곡선이나 원을 만들 수 있다. 새 클릭은 누적 오차를 즉시 보정한다. 멈춘 상태에서는 오차가 새로 쌓이지 않는다.

나침반은 항상 신뢰할 수 있다. 우하단 바늘은 -actualHeading 회전으로 실제 북쪽을 정확히 보여준다. 수치 방위각도 실제 이동 방향이다. 오른손 작은 나침반 바늘은 화면 북쪽을 가리킨다. 나침반은 위치나 가까운 출구를 알려주지 않는다. [Souman et al. (2009)](https://pubmed.ncbi.nlm.nih.gov/19699093/)에서 영감을 얻었지만 모델 계수는 게임 설계값이며, 올바르게 사용한 나침반의 실패를 주장하지 않는다.

## 저장과 활성 시간

버전 있는 localStorage에 위치, 시드, 두 방향, 드리프트 상태, 보행 거리, 경과 활성 시간, 경계 이탈 여부, 최근 발자국을 저장한다. 5초마다 그리고 방향/정지/일시정지/탭 숨김/페이지 종료 시 자동 저장한다. 이전 유효 저장의 백업을 유지한다. 재실행은 정확한 위치를 복구하며 정지 상태에서 시작한다. 오프라인이나 백그라운드 시간은 이동으로 계산하지 않는다. 숨겨진 탭은 일시정지하고 복귀 시 delta를 초기화한다. Reset Journey는 확인 후 중심에서 새로 시작한다. 저장 공간 오류는 화면에 표시한다.

## 화면과 조작

480×270 Canvas 2D, 16:9 레터박스, nearest-neighbor 확대. 정확한 수직 90° 탑다운, 캐릭터는 항상 (240,135). 클릭/터치 한 번으로 계속 보행, 다시 누르면 회전/보정. 중심 6px 이내는 무시. Space 정지/재개, H Field Notes, Escape 일시정지. 메뉴와 나침반 클릭은 이동 방향에 영향을 주지 않는다. 녹색 계열의 절제된 HTML UI와 접근 가능한 버튼을 쓴다.

원본 낮/밤 스프라이트의 8방향/6걸음 프레임을 거리 기반으로 재생한다. 실제 물리는 연속 각도이며 이미지와 손의 부착점만 8방향이다. 원본 모래 아틀라스와 결정적 좌표 해시로 근처 타일만 그린다. 발자국은 월드에 고정하고 번갈아 남기며 55초에 걸쳐 희미해지고 최대 320개를 유지한다. 모든 원본 이미지는 수정 없이 보존한다.

## 현실 시간의 빛

브라우저 실제 로컬 시계. 06:00 일출 / 12:00 정오 / 18:00 일몰. 05:30–06:30, 17:30–18:30 황혼 블렌딩. 태양 동→남→서, 그림자 반대 방향/정오에 짧아짐. 밤 18:00–06:00에는 왼손 랜턴, 따뜻한 동적 반경 조명, 차가운 암부. HUD는 조명 이후에 읽기 쉽게 유지한다. 위치 기반 천문학 계산이나 시간 가속은 없다.

## 개발·배포·검증

HTML/CSS/ES Modules/Canvas 2D만 사용, 엔진/백엔드 없음. Pages 주소 https://aru-tris.github.io/Desert-Finding/. 모든 URL 상대 경로. Node 단위 테스트 및 실제 Chromium 테스트 실행. 면적/속도/모든 경계/저장/드리프트/나침반/엔딩/빛/터치/서브패스를 검증한다. 명시적 debug=1에서만 원거리 이동과 장시간 QA 메서드를 제공하며 정상 저장과 분리한다. 테스트와 시각 검증 후 커밋/푸시/배포 상태를 보고한다.
